## Priorities and hypotheses

1. Generalize conservative whole-pair separation certificate. Current wow_sdf_pair_clear admits only named passive_motor_stop pairs, now removed. Extend selectively to expensive empty pairs with correct margins/thresholds and a cheap-to-expensive rejection hierarchy; reuse proof within bounded relative displacement. Existing proof certifies zero-sublevel separation only and currently gates ordinary collider, not supplement: extending to skip both requires proving the supplement threshold too. Unknown/near-contact/budget-exhausted cases fall back. Removing all observed empty-pair time has ideal pair-layer ceiling~2.12xupper/~1.62xforearm, not promised end-to-end gain.
2. Audit per-world cache ownership. Both pair certificate and swept-candidate caches are thread_local and keyed by pair/model, not world. Different worlds visiting the same worker can evict each other's entries; this is a concrete design possibility, not a measured miss diagnosis. Collect hit/miss/rebuild counters perworld/pair; give each world small bounded cache or stable worker partition if churn is demonstrated. Absolute world-pose exact memo also misses common rigid motion; change only with correct contact transform semantics, never copy world contact positions unchanged.
3. Positive assembly-contact patch maintenance. Existing swept tree already culls negative samples but reevaluates all surviving candidate samples. For dominant shoulder/servo pairs, retain contact patches and bound unseen competitors, reevaluate distances/normals at new pose and fallback on large motion/new feature. Audit counts of samples/gradients/SDF calls before design. Seed ordinary search from previous contacts with exhaustive fallback; blindly reducing40x40 failed prior parity checks. Eliminating entire top2forearm pairs is only1.36xpair-layer ceiling, so combine with empty-pair elimination.
4. Conditional structural simplification after physical attachment. Audit whether completed subassemblies are actually rigidly fixed (structural joint/weld), or merely task-successful/friction-held. Only physically guaranteed rigid relationships justify removing redundant internal collisions or merging collision topology; preserve all exposed exterior collisions. Do not infer rigidity from stage name. This is a potential hinge-like simplification, not presently proven applicable.
5. Selective analytic contacting features. Simple gripper pads/servo faces may support exact planes/boxes/convex features while complicated holes retain CAD SDF. Conservative enclosing primitives can safely reject pairs without replacing geometry. Positive-contact replacements require geometric validation and a physics-version change if approximate; do not reinstate global coarse-box physics.
6. CPU layout/load balance. Current tests use2SMT siblings on1physicalcore. Compare equal physical-core allocations with1vs2threads/core before fleet conclusions. Stage cost329xforearm/loose makes synchronous barriers/stragglers plausible; profile actual fleet worker idle times and SGS sampling before dynamic scheduling. Scheduling must preserve task distribution and on-policy batch semantics.

Next implementation order: instrument cache hits and rejection workload; generalize separation proof for ranked empty pairs; qualify across bank, near-contact boundary motions and actual policy rollouts; then optimize positive shoulder/servo patches. Collect repeated actual-policy timings with physical-core accounting and learner/worker spans. Avoid solver/GPU/point-cloud optimization now.
